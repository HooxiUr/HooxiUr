### About / 关于

I build things in the spaces where typed code, clean UI, and Chinese-language community software meet.
Most of my work is in **C# / .NET**, **TypeScript**, and **PHP** — with a soft spot for restrained,
typography-first interfaces over badge-heavy layouts.

平常在中文社群的软件工具之间穿梭，写强类型代码，做克制排版的界面。
主力是 **C# / .NET**、**TypeScript** 和 **PHP**，偏爱简洁的信息呈现。
